# Data Dictionary

O dicionário é mantido no banco (`data_dictionary`) e atualizado a cada pipeline a partir do schema real dos datasets
+ descrições curadas em `data_platform/dictionary/catalog.py`. Consulte em **Data Lakehouse › Data Dictionary** ou
`GET /api/data/dictionary?dataset=<key>&q=<texto>`. Campos-chave: ver `docs/architecture/DATA_MODEL.md`.
